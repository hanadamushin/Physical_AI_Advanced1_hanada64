# EEGジェル処置アシスト：ピストン連動・後方270°・16電極版 v0.7

頭部模型の周囲を移動する簡略ロボットが、電極ごとの模擬インピーダンスに応じて処置を行うデモです。

## Colabで使う

1. Google Colabの「ファイル → ノートブックをアップロード」で `EEG_Gel_Assist_Colab.ipynb` を開きます。
2. CPUランタイムで「ランタイム → すべてのセルを実行」を選びます。GPUは必要ありません。
3. 依存ライブラリの導入、モデル学習、経路生成、動画生成が順に実行されます。
4. ノートブック内で動画を確認し、最後のセルで動画・処置ログ等のZIPを保存します。

ローカルではMuJoCo 3.17.0 / Python 3.12で生成・描画まで確認済みです。作成者本人からColabですべてのセルを最後まで実行できたとの報告を受けています。Colab用セルでは画面を開かずにCPUで描画するOSMesaを設定しています。描画中は進捗が表示されます。

## 今回の完成範囲

- 頭部模型、10–20法の標準位置から選んだ16電極、後方270°の弧状レール上の台座、5関節アーム、固定した注射器を配置。
- 顔の正面90°には台座を入れず、頭の後ろを回って移動。世界座標での台座の可動域は-45°〜225°、顔の正面は-90°です。レールも同じ270°だけを描画し、両端を明示。
- 額の電極へはレールの左右端から到達します。肩と手首の旋回により、台座を電極の正面へ移動せずに注射器先端の位置・向きを合わせます。270°制約は台座の中心角に対するもので、アーム全体をこの扇形に閉じ込めるものではありません。
- 電極名：Fp1, Fp2, F7, F3, F4, F8, T7, C3, C4, T8, P7, P3, P4, P8, O1, O2。今回は16点の部分集合であり、Fz/Cz/Pzや耳の基準電極を含む全配置ではありません。T7/T8/P7/P8は旧表記T3/T4/T5/T6に対応します。
- 模型の鼻根点・後頭点・左右耳前点を楕円体の前後左右の赤道上に定義。鼻根〜後頭の弧と耳前〜耳前の弧を数値積分し、10%・30%・50%・70%・90%位置を算出します。外周は各方向の弧の80%高さで構成した周回線を弧長で分割し、Fp1/Fp2等を配置します。F3/P3等はFp1〜C3〜O1を通る模型上の曲線の25%・75%位置です。
- 左右対称の理想化した模型に10–20法の弧長比率を適用するデモです。実在の人の頭を実測・登録する処理はありません。
- 顔の基準を鼻・目・耳で明示し、Fpは額の上、T7/T8は耳の上、C3/C4はその内側の頭頂寄りに配置。被計測者の左を世界座標+X、前を-Y、上を+Zに統一。正面像のFp1は画面右に見えます。
- 上面マップは単純な真上からの投影をやめ、頭頂からの角度に応じて展開する図に変更。前が上・被計測者の左が左になる表示に統一。3D像は頭皮に沿う薄い電極と位置ガイド、見えている電極の名前を表示します。ジェルの位置も頭皮の法線方向に沿わせました。
- 正面・左側面・後面・上面の実際の3D描画を比較し、位置・名前・左右を確認。
- 頭の寸法を初版より20%大きくし、カメラも近づけて表示。首と支柱は削除。
- 空の注射器で開始し、模型の後方に移したジェル容器へ移動して補給。残量不足時には後方の容器へ戻って再補給し、電極への処置を再開。終了時も頭の後ろに駐機。
- 注射器容量は仮想0.48 mL、16電極版の容器容量は仮想4.8 mL。電極数に比例して容器容量を設定し、容器の液面と両者の残量を更新。補給量・処置量・残量の収支を確認。
- 注射器を透明な筒・筒内のジェル・目盛・ピストンの栓・ロッド・押し板で構成。ピストンには独立したスライド関節を追加し、吸引時に引き、注入時に押します。移動中はその位置で保持します。
- ピストンの引き量 = 仮の全ストローク × 仮想残量 / 仮想容量、として全フレームで同期。筒内ジェルの長さも同じ引き量に一致させます。見やすさのための仮寸法で、外形・内径・ストロークが実物の0.48 mL注射器を表すものではありません。
- 右上に、同じ3D模型内の注射器を追う専用カメラの拡大映像を追加。吸引はPULL、注入はPUSHとして矢印も表示。スライド関節の動きを拡大表示します。
- 問題のある電極を弧に沿って訪問し、退避 → 台座移動 → 位置合わせ → 接近 → 吐出 → 再測定 → 退避を実行。正面を横切って一周する処理を廃止し、必要に応じて弧上で折り返します。同じ位置で追加処置が必要な場合は、再測定後に処置を繰り返します。
- AIは合成データ1,600例で学習するリッジ回帰モデル。候補の注入量ごとの改善量を予測し、目標到達が見込める最小量を選択。到達が見込めなければ1回の上限量を選択。
- 処置後の観測から各電極の予測補正係数を更新。巡回先の順序と停止条件は決められたルール。
- 意図的に改善しない電極T7は、2回の処置後に要確認へ切り替え、追加処置を停止。
- 電極の状態を赤・緑・橙で、模擬ジェルを水色の小さな塊で表示。左上は電極・台座の平面図で、処置対象の電極名を表示。右側に16電極の数値と状態を同時表示。

## 既定の実行結果（seed=42）

- シミュレーション353秒を2倍速で176.5秒の動画として出力。動画内に「2x PLAYBACK」と明記。右上の時計はシミュレーション時刻です。
- 処置20回、補給7回（開始時の1回を含む）。台座は全フレームで-45°〜225°に収まり、補給往復や駐機でも正面90°を通りません。
- 容器からの吸引3.00 mL、電極への使用2.76 mL、注射器の残量0.24 mL、容器の残量1.80 mL（いずれも仮想量）。
- 開始時に目標を満たす電極は4個。追加処置で11個が目標に到達し、最終的に15/16個が目標内。
- 残るT7は要確認で終了。
- 描画フレームごとに、アーム・注射器等と頭・鼻・耳・容器の縁や底の距離および関節可動域を確認。既定実行の最小離隔は約9.9 mm。

## モデルの意味と限界

実際の計測値、実際のジェル量の適正値、人体への処置を再現・検証するものではありません。表示の10 kOhmはデモの任意の目標で、臨床上の基準ではありません。mLも仮想処置量です。

模擬環境では、注入量に対してインピーダンスが指数関数で改善する仮定を置いています。電極間で反応を変え、観測にノイズを加えています。AIの学習と評価は別の乱数で生成した合成データですが、同種の仮定に基づいており、実測への汎化や熟練度の差の解消を示しません。

MuJoCo上で関節位置を直接設定する運動学デモです。ピストンのスライドと残量の同期は実装しています。モータの駆動力、圧力、実際の流体、実機の動力学、自己衝突、連続時間での衝突回避、毛髪やキャップ、実際の電極接触、注射器の把持は未検証です。注射器本体は最初からアームに固定し、ジェルは体積状態と表示で抽象化しています。

接近中の注射器先端は模型表面から離した位置で止めます。模型との離隔の確認は、人体に対する安全性の証明ではありません。

## ローカル実行

```sh
pip install -r requirements.txt
python demo.py --out output
```

`--no-video` で経路・フィードバック処理のみを確認できます。`--seed 43` のように測定ノイズを変更できます。

既定は `--electrodes 16 --playback 2` です。今後は電極数を32まで増やす方針で、32点では頭部模型の19位置と追加位置を使います。追加位置は周辺点からの球面補間による近似です。`--electrodes 32` の経路・処置・補給・残量チェックも確認済みです。32電極版の動画は今回未作成です。32では2倍速でも動画が3分を超えるため、提出用の尺調整が別途必要です。

確認には通常条件だけでなく、全16電極の初期インピーダンスを高くした条件も使用。初めから良好な電極を含め、全電極への処置経路を通ることを確認しました。各電極への先端位置・先端方向と、台座が270°内に収まることも確認しています。これらは模型・運動学での確認であり、実機や人体の安全性の検証ではありません。

ピストンについては、全フレームで残量と引き量が一致し、吸引時に引き量が増加、注入時に減少、その他の動作中は保持されることを確認しています。ピストンの栓・ロッド・押し板も模型や補給容器との離隔チェックに含めています。

課題として提出する場合は、レポートに独自の目的・設計・実行結果・上記の仮定を説明し、動画をYouTube、コードを公開GitHub、レポートとURLをOmniCampusへ提出する作業が別途必要です。本リポジトリは提出用v0.7の使用コードです。
